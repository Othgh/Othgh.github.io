开始记录：这个博客是怎么搭起来的

折腾了一个下午，终于把这个博客立起来了。用的 Hexo + Icarus，纯静态，挂 GitHub Pages 上，不要钱也不用服务器。

为什么选这套

  • Hexo：静态站点生成器，写完 Markdown 一条命令生成整站，快得离谱
  • Icarus：三栏布局（左边个人信息 / 中间正文 / 右边目录），自带代码高亮、本地搜索、深色代码主题
  • GitHub Pages：托管免费，git push 即发布

日常写文章

几个坑

  1. CDN：Icarus 默认用 cdn.jsdelivr.net，国内会被墙，改成 fastly.jsdelivr.net 就好了（_config.icarus.yml 的 providers）
  2. 本地搜索：insight 搜索依赖 hexo-generator-searchdb 生成 content.json，路径要写成 content.json 而不是默认的 search.xml
  3. 图片：source/img/ 下的文件可以直接用 /img/xxx.png 引用

后面想做的

  • 深色模式切换（Icarus 原生没有，得自己加）
  • 评论区（挂 giscus，用 GitHub Discussions）
  • 把之前的笔记慢慢搬过来

第一篇就先这样，开工。
